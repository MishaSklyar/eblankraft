📖 Lua Mod Script API Довідник

Усі скрипти виконуються на повноцінному рушії Lua 5.3.

👤 Player (Гравець)
Player.setCreative(bool) / Player.isCreative() — Креативний режим
Player.setFlying(bool) / Player.isFlying() — Режим польоту
Player.setFlySpeed(speed) — Швидкість польоту (за замовч. 12)
Player.setGodMode(bool) — Безсмертя (не отримує шкоди)
Player.setInstantBreak(bool) — Миттєве ламання блоків 1 ударом
Player.setInfiniteBlocks(bool) — Нескінченні блоки при ставленні
Player.setReach(distance) — Дальність дотягування (в креативі 10.0)
Player.getPos() — Повертає x, y, z
Player.setPosition(x, y, z) — Телепортувати гравця
Player.getHealth() / Player.setHealth(hp) — Здоров'я (0..100)
Player.getHunger() / Player.setHunger(h) — Голод (0..100)
Player.giveItem(itemId, count) — Видати предмет в інвентар
Player.clearInventory() — Очистити весь інвентар
🌍 World (Світ та Блоки)
World.getBlock(x, y, z) — Отримати ID блоку
World.setBlock(x, y, z, blockId) — Поставити блок
World.setBlocks(x1, y1, z1, x2, y2, z2, blockId) — Заповнити область блоками
World.explode(x, y, z, radius, power) — Створити вибух
World.spawnTNT(x, y, z, vx, vy, vz) — Кинути динаміт
World.BLOCKS.DIAMOND_BLOCK, World.BLOCKS.PLANKS, World.BLOCKS.AIR тощо
⚡ Events (Події)
Events.on("onTick", function(dt) ... end) — Кожен кадр гри
Events.on("onKey", function(code, isDown) ... end) — Натискання клавіші (напр. "KeyF")
Events.on("onChat", function(msg, sender) ... end) — Повідомлення в чаті
Events.on("onBlockBreak", function(x, y, z, blockType) ... end)
Events.on("onBlockPlace", function(x, y, z, blockType) ... end)
Events.on("onAttack", function(target, dmg) ... end)
🎮 Game (Гра)
Game.toast("Текст") — Плаваюче сповіщення на екрані
Game.chat("Текст", "Відправник") — Повідомлення в чат
Game.playSound("playClick") — Відтворити звук
