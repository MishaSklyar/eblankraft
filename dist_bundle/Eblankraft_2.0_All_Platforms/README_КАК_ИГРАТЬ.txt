=============================================================
             EBLANKRAFT 2.0 — ВСЕ ПЛАТФОРМЫ В ОДНОМ МЕСТЕ
=============================================================

Добро пожаловать в мега-сборник Eblankraft 2.0!
Здесь собраны версии игры под любую платформу:

-------------------------------------------------------------
1. WINDOWS (Папка "Windows/")
-------------------------------------------------------------
- Открой папку "Windows" и дважды кликни "Run_Game.bat" (или "eblankraft.exe").
- Управление: WASD (ходьба), Мышь (обзор), Space (прыжок), ЛКМ (ломать), ПКМ (ставить),
  1..9 / Колесико (хотбар), X / Z (кейсы), Esc (меню).
- Поддерживает любые геймпады (Xbox / PS / GameCube).

-------------------------------------------------------------
2. LINUX (Папка "Linux/")
-------------------------------------------------------------
- Запуск через терминал: "./run_linux.sh" (или напрямую "./eblankraft").
- Чистый нативный 64-битный бинарник с аппаратным OpenGL.

-------------------------------------------------------------
3. ANDROID (Папка "Android/")
-------------------------------------------------------------
- Установи файл "eblankraft-pro.apk" на телефон или планшет Android.
- Полная поддержка сенсорного управления, джойстиков и кейсов.

-------------------------------------------------------------
4. NINTENDO GAMECUBE / WII (Папка "GameCube_Wii/")
-------------------------------------------------------------
- "eblankraft.dol" — запускается напрямую через эмулятор Dolphin или Swiss на реальной GameCube/Wii.
- "eblankraft_gamecube.iso" — образ диска для записи или эмулятора.
- Управление: Main stick (ходьба), C-Stick (камера), (A) прыжок, R/B ломать, L/Y ставить, X/Z кейсы.

-------------------------------------------------------------
5. SONY PSP / PPSSPP (Папка "PSP/")
-------------------------------------------------------------
- Файл "EBOOT.PBP".
- На эмуляторе PPSSPP: открыть файл "EBOOT.PBP".
- На реальной PSP: скопировать в папку "PSP/GAME/EBLANKRAFT/EBOOT.PBP".

-------------------------------------------------------------
6. БРАУЗЕР (Папка "Browser/")
-------------------------------------------------------------
- Просто открой файл "index.html" в любом браузере (Chrome, Firefox, Edge).
- Играет без интернета прямо из файла!

Приятной игры вам и вашим друзьям! 🚀🔥
