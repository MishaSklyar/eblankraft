### 💻 На комп'ютері (Клавіатура + Миша):
- **W, A, S, D** — Рух персонажа
- **Миша** — Огляд (натисни на екран для захоплення миші PointerLock)

- **Shift** — Присідання

- **ПКМ** — Поставити блок зі слоту хотбару / З'їсти їжу
- **1 – 9** — Швидкий вибір предмету на хотбарі
- **E / B / I** — Відкрити меню (Інвентар, Крафт, Кейси, Апгрейдер, Скіни, Мусор)
- **Q** — Викинути активний предмет (Drop Item)
- **V** — Перемикання виду від 3-ї особи / 1-ї особи
- **ESC** — Пауза / Меню налаштувань

- **Лівий джойстик** — Рух персонажа
- **Правий бік екрану (Touch)** — Плавний огляд камерою
- **Кнопка ⛏️** — Ламати блок або атакувати
- **Кнопка 🧱** — Поставити блок / З'їсти їжу
- **Кнопка ⬆️** — Стрибок
- **Кнопка 🎒** — Відкрити повний інвентар, крафт, кейси, апгрейдер
- **Кнопка 🌌** — Меню переміщення між світами (Overworld / Nether / End)
- **Кнопка 👤** — Перемикання виду від 3-ї особи (щоб милуватися скіном!)
- **Кнопка ⛶** — Повноекранний режим

## 🚀 Як запустити гру

### Варіант 1: Через вбудований сервер
```bash
python3 server.py
```
Сервер запуститься на порті **8080** (наприклад, `http://localhost:8080`).

### Варіант 2: Автономний один файл (Standalone)
Відкрий файл `eblankraft_standalone.html` у будь-якому браузері (Chrome, Firefox, Safari, Edge) навіть без сервера чи інтернету!

## Спільний світ у mainline

Запустіть `python3 server.py`, відкрийте `http://localhost:8081/`
(або `http://localhost:8081/web/`) та меню «Мультиплеєр».
У розділі «Спільний світ — без PvP» введіть код кімнати, виберіть виживання
або творчість і натисніть «Створити / увійти». Друзі використовують однакову
адресу сервера й код. Для локальної мережі замініть localhost на IP сервера.

Поле адреси підтримує `ws://` та `wss://`; для локального Python-сервера
використовуйте `ws://localhost:8082/ws`. Перший гравець задає режим кімнати.
Спільними є генерація світу, зміни блоків, позиції гравців, предмети в руках
та чат. Інвентар зберігається в браузері окремо для кожної кімнати.
Сервер не перевіряє походження предметів; моби та підбір предметів локальні.
Зміни світу живуть до перезапуску сервера. Подорож в інший вимір виходить
зі спільної кімнати. PvP доступний окремо через попередні кнопки арени.

Cloudflare Worker також підтримує цей протокол; його кімнати живуть у пам'яті
окремого Worker instance, без постійного сховища або координації між instance.
Оновлення Worker потребує окремого розгортання.

Перевірки: `node tests/cooperative-world-regressions.cjs`,
`node tests/edge-cooperative-regressions.cjs`,
`python3 -m unittest discover -s tests -p test_competitive_server.py`.

### C4 (веб-версія)

C4 доступний у каталозі предметів і крафтиться з 2 TNT та 1 залізного злитка. Виберіть C4 і натисніть ПКМ (на телефоні — кнопку встановлення), щоб поставити заряд біля вибраного блока. T, середня кнопка миші або кнопка 💣 підриває всі встановлені C4; якщо зарядів немає, ця дія кидає звичайний TNT. Ліміт — 16 зарядів, радіус руйнування — 5,5 блока. Заряди тимчасові: не зберігаються при виході зі світу й не синхронізуються між гравцями. На соревновальній арені C4 вимкнено.
