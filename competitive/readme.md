- **Пробіл** — Стрибок
- **Shift** — Присідання

- **ПКМ** — Поставити блок зі слоту хотбару / З'їсти їжу
- **1 – 9** — Швидкий вибір предмету на хотбарі
- **E / B / I** — Відкрити меню (Інвентар, Крафт, Кейси, Апгрейдер, Скіни, Мусор)
- **Q** — Викинути активний предмет (Drop Item)
- **V** — Перемикання виду від 3-ї особи / 1-ї особи
- **ESC** — Пауза / Меню налаштувань

- **Лівий джойстик** — Рух персонажа
- **Правий бік екрану (Touch)** — Плавний огляд камерою
- **Кнопка ⛏️** — Ламати блок або атакувати
- **Кнопка 🧱** — Поставити блок / З'їсти їжу

## 🚀 Як запустити гру

### Варіант 1: Через вбудований сервер
```bash
python3 server.py
```
Сервер запуститься на порті **8080** (наприклад, `http://localhost:8080`).

### Варіант 2: Автономний один файл (Standalone)
Відкрий файл `eblankraft_standalone.html` у будь-якому браузері (Chrome, Firefox, Safari, Edge) навіть без сервера чи інтернету!

## Сервер 8082: блоки и инвентарь

Запуск из корня проекта: `python3 competitive/server.py`, затем открыть
`http://localhost:8081/competitive/`. Ломание и установка блоков передаются
другим игрокам; изменения комнаты (включая воздух после ломания) передаются
при подключении. Изменения живут в памяти до перезапуска сервера.

Клиент передаёт все 27 слотов инвентаря и выбранный слот хотбара. Сервер
проверяет структуру, количества и индексы, хранит снимок и синхронизирует
предмет в руках с другими игроками. Это клиентский инвентарь: сервер пока
не проверяет происхождение предметов, добычу или рецепты крафта.

Проверки: `node tests/lua-server-regressions.cjs` и
`python3 -m unittest discover -s tests -p test_competitive_server.py` из корня.

## Совместная игра без PvP

1. Запустите `python3 competitive/server.py` из корня проекта.
2. Откройте `http://localhost:8081/competitive/` и меню «Мультиплеєр».
3. В разделе «Спільний світ — без PvP» задайте код комнаты и выберите
   выживание или творческий режим. Нажмите «Створити / увійти».
4. Друзья открывают тот же сервер и вводят тот же код. Для игры по локальной
   сети вместо localhost используйте IP компьютера, на котором запущен сервер.

Первый игрок задаёт режим комнаты. Сервер передаёт всем одинаковое зерно мира,
изменения блоков, позиции, предметы в руках и чат. Удары и чужие взрывы не
наносят урон игрокам в совместной комнате. Дуэли и арены сохраняют PvP.

Инвентарь сохраняется в браузере отдельно для каждой комнаты. Изменения мира
хранятся в памяти сервера до его перезапуска. Совместные комнаты используют
основной мир; переход в другой мир отключает игрока от комнаты. Мобы и сбор
выпавших предметов пока обрабатываются локально, без общего серверного состояния.

Проверка меню и подключения: `node tests/cooperative-world-regressions.cjs`.
