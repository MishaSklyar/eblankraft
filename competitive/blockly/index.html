📜 Lua-код (генерується автоматично)
❓ Як користуватись
  1. Почни з блоку 🧩 Мод (id, назва, автор).
  2. Додай ⚡ Подію (напр. onChat) або 💬 /команду.
  3. Всередину поклади дії: 🎮 тост, 🧍 видати предмет, 🌍 блоки…
  4. Тисни 💾 Зберегти в гру → відкрий гру → вкладка Моди → увімкни свій мод.
  5. Блоки = звичайні Логіка / Цикли / Математика / Текст / Змінні теж доступні.

Blockly лежить локально в vendor/ — інтернет не потрібен. Гра має бути відкрита в тому ж браузері (localStorage спільний), або скопіюй Lua у редактор модів вручну.
